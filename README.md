# WishDuck Website

WishDuck is a family growth and wish motivation app for recognition, stars, habits, exploration, and challenge achievements.

This repository contains the standalone bilingual website and public legal pages:

- `index.html` - Chinese landing page
- `index_en.html` - English landing page
- `gameplay.html` / `gameplay_en.html` - challenge gameplay overview
- `support.html` / `support_en.html` - support page
- `privacy.html` / `privacy_en.html` - privacy policy
- `terms.html` / `terms_en.html` - terms of use

The site is static and can be hosted directly with GitHub Pages or any static hosting provider.
