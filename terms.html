心愿鸭使用条款

使用心愿鸭 WishDuck 即表示你同意以下条款。心愿鸭是一款帮助家庭管理成长激励、星星奖励、任务挑战、徽章和心愿目标的工具，不替代家长对家庭教育和安全的判断。

生效日期 / Effective Date: 2026-07-27

1. 接受条款 / Acceptance

如果你不同意本协议，请不要使用心愿鸭。我们可能根据产品迭代更新功能、文案、商品、权益边界或本条款。

2. 产品定位 / Product Positioning

心愿鸭不是金融产品、银行账户、电子钱包、记账服务或儿童社交网络。App 内的星星仅代表家庭内部认可和激励，不具有现金价值，不能兑换真实货币，也不构成我们对任何金钱支付的承诺。

3. 家长责任 / Parent Responsibility

  • 创建和管理家庭、孩子、规则、心愿和挑战；
  • 根据孩子年龄、能力、健康状态和家庭情况安排任务；
  • 判断奖励星星、认可方式和心愿目标是否合适；
  • 审核孩子提交的进度，或直接记录完成情况；
  • 管理家长 PIN、设备权限和购买行为。

4. 儿童使用 / Child Use

孩子可以在家长允许下使用孩子端查看任务、星星、心愿和徽章。家长应确保孩子在适当监督下使用 App。心愿鸭不要求孩子创建公开账号或公开分享个人资料。

5. 任务与挑战 / Tasks And Challenges

任务、推荐模板、挑战包和特别活动仅作为家庭实践建议。请根据实际情况调整，不要让孩子完成危险、不适龄、不健康或不适合家庭情况的任务。

挑战开始后会根据选择的开始时间和周期生成每天任务。当天所有必需任务完成后，当天状态才算完成；全部天数完成后，挑战成功并可解锁对应徽章或奖励。

6. 付费与内购 / Payments And In-App Purchases

心愿鸭的商业模型可以包括免费功能、Pro 一次性购买、付费主题挑战包和可选 Coffee 支持。实际商品、价格、税费、退款和可用性以 App Store 页面和 Apple 规则为准。

Pro

Pro 解锁更广的 App 能力，例如外部 Pro 任务使用、Pro 挑战体验和未来 Pro 能力。Pro 不自动解锁所有付费主题挑战包。

主题挑战包 / Theme Challenge Packs

购买主题挑战包只解锁该包内部的挑战内容、进阶任务、徽章、主题奖励和未来相关分享素材。购买某个主题包不解锁其他主题包，也不解锁外部 Pro 任务库。

Coffee 支持 / Coffee Support

Coffee 支持是可选支持，不解锁核心功能。

7. 数据与设备 / Data And Devices

第一版数据主要保存在本地设备。请自行保护设备、系统锁屏密码、Apple ID 和家长 PIN。因设备丢失、系统故障、误删 App、清除数据或未备份导致的数据丢失，可能无法恢复。

8. 允许使用与限制 / Acceptable Use

  • 不得违反适用法律或平台规则；
  • 不得将星星、奖励或心愿描述成真实金融产品；
  • 不得记录违法、侵权、伤害儿童或不适合家庭使用的内容；
  • 不得试图破坏、逆向、绕过付费权益或干扰 App 正常运行。

9. 免责声明 / Disclaimer

我们会努力保证应用稳定可靠，但不承诺心愿鸭适用于所有家庭、所有教育场景或所有孩子。因使用本 App 设置家庭规则、任务、奖励或心愿目标产生的家庭决策，由用户自行负责。

10. 变更与联系 / Changes And Contact

若你不同意更新后的条款，可以停止使用 App。如有问题，请联系 support@wishduck.app。
